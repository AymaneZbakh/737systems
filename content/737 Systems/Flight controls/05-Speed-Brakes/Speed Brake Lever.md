# Speed Brake Lever
🔗 [[Speed Brakes|← Speed Brakes]]

> [!abstract]
> Supplies mechanical inputs to the Spoiler Mixer to control ground and flight spoilers. Placing in ARM detent enables auto speedbrake deployment on landing.

---

## Lever Positions

| Position | Description |
|----------|-------------|
| **DOWN** | All spoiler panels faired (retracted) |
| **ARMED** | Arms auto speedbrake system; auto speedbrake actuator will move lever to UP when deployment criteria are met |
| **50%** | Load alleviation retract point (selected a/c only) |
| **FLIGHT DETENT** | All flight spoilers at maximum — **in-flight maximum limit** |
| **UP** | All flight + ground spoilers at maximum — **ground only** |

---

## Gates & Stops

> [!warning] Flight Detent Gate
> A gate at FLIGHT DETENT prevents inadvertent selection of UP in flight.
> Moving beyond requires deliberate force through the gate.
> **Deploying speedbrakes beyond FLIGHT DETENT in flight causes buffeting and is prohibited.**

> [!note] SFP Lever Stop
> On SFP (Scimitar Fence Performance / 737-800) aircraft:
> When flaps are **UP**, a lever stop prevents movement of the speedbrake lever beyond FLIGHT DETENT in flight.

---

## Load Alleviation (Selected Aircraft)

- When speed brake load alleviation feature is activated (high gross weight + high airspeed): speed brakes **retract to the 50% position**
- Manual override possible but requires **increased force** on lever

---

## Mechanical Path

```
Speed Brake Lever
  → Ratio Changer Input Rod
  → Spoiler Mixer (combines with F/O roll input)
  → Flight spoiler actuators via control cables
  → (Beyond FLIGHT DETENT) → Ground Spoiler Control Valve mechanical link → Ground spoilers
```
