# Aileron Input Shaft
🔗 [[Roll Control|← Roll Control]]

> [!abstract]
> The Aileron Input Shaft transmits CPT control wheel inputs to the Aileron PCUs via the pogos. It is the mechanical link between the cockpit and the hydraulic actuation system.

---

## Function

- Receives input from CPT control wheel via cable runs
- Connected to both Aileron PCUs via **4 pogos** (2 per PCU)
- Rotation of input shaft → pogo extension/retraction → input cranks move → PCU actuates
- Also connected to [[Aileron Feel and Centering Unit|Aileron Feel & Centering Unit]]
