# Control Wheels
🔗 [[Roll Control|← Roll Control]]

---

## Trim Indicator

- Trim indicator placard located on **top of each control wheel**
- **1 trim unit = 6° of control wheel rotation**

## Spoiler Engagement Threshold

| Condition | Value |
|-----------|-------|
| Wheel displacement for spoiler activation | > 10° |
| In trim units | = 1.6 units |
| First spoilers to extend | Panels 4+5 and 8+9 (inner pairs) |

## Interconnection

- Both wheels interconnected by cables through the [[Transfer Mechanism|Aileron Transfer Mechanism]]
- CPT wheel → aileron path (via Aileron Input Shaft)
- F/O wheel → spoiler path (via Spoiler Control Shaft → Spoiler Mixer)
- With transfer mechanism: either wheel can command either path after jam isolation
