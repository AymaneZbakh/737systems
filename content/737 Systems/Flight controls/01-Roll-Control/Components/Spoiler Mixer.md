# Spoiler Mixer
🔗 [[Roll Control|← Roll Control]]

> [!abstract]
> Mechanically combines roll inputs (from F/O control wheel via Spoiler Control Shaft) and speedbrake lever position. Sends combined output to flight spoiler actuators via control cables.

---

## Inputs

| Input | Source |
|-------|--------|
| Roll input | [[01-Roll-Control/Components/Spoiler Control Shaft|Spoiler Control Shaft]] (F/O side) |
| Speedbrake lever position | [[05-Speed-Brakes/Speed Brake Lever|Speedbrake lever]] via ratio changer input rod |

---

## Outputs

- Combined mechanical signal sent to **flight spoiler actuators** via control cables
- When speedbrake lever is beyond FLIGHT DETENT: Spoiler Mixer sends an **open command** to the [[Ground Spoiler Control Valve|Ground Spoiler Control Valve]]

---

## Location

Located in the **main wheel well**, visible during flight control check. Co-located with the Aileron Spring Cartridge and Spoiler Control Shaft.
