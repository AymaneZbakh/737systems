# 🎚 Pilot Controls & Indications
> [!abstract] Overview
> Cockpit controls, switches, and indications for all flight control systems. Includes FLT CONTROL switches, stabilizer trim controls, alternate flaps, speed brake lever, and MFD surface position display.

## FLT CONTROL Switches (A & B)

| Position | Action |
|----------|--------|
| **ON** (guarded) | Normal — hydraulic power to all surfaces |
| **STBY RUD** | Activates standby pump + opens standby rudder shutoff valve |
| **OFF** | Closes shutoff valve — isolates ailerons, elevators, rudder from that hyd system |

> [!warning] LOW PRESSURE light (Amber)
> Low hydraulic pressure to respective flight control surfaces. Check hydraulic system status.

## Stabilizer Trim Controls

| Control | Function |
|---------|----------|
| Trim switches (control wheels) | Spring-loaded; A/P disconnects if engaged |
| STAB TRIM MAIN ELECT cutout | Deactivates trim switch operation |
| STAB TRIM AUTOPILOT cutout | Deactivates A/P trim + disconnects A/P |
| OVERRIDE switch | Bypasses column-actuated cutout |
| Manual trim wheel | Backup; overrides electric trim |
| STAB TRIM indicator | Shows trim units + takeoff green band |

---

## Alternate Flaps Controls

| Control | Action |
|---------|--------|
| Master switch → ARM | Closes TE bypass valve + arms position switch |
| Position switch → DOWN (momentary) | Fully extends LE devices via standby hyd |
| Position switch → DOWN (hold) | Electrically extends TE flaps to desired position |
| Position switch → UP | Electrically retracts TE flaps |

---

## Trim Controls Summary

| Trim | Control | Mechanism |
|------|---------|-----------|
| Aileron | Dual switches (simultaneous) | Repositions aileron feel & centering unit |
| Rudder | RUDDER trim knob | Repositions rudder feel & centering unit |
| Stabilizer | Trim switches / manual wheel | Electric motor or direct cable |

---

## MFD Surface Position Indicator

Accessed via **SYS** button on MFD — displays on lower DU:

| Display | Shows |
|---------|-------|
| FLT SPLR | Spoiler panels #4 and #9 (L & R) |
| AIL | Aileron position (max up / neutral / max down) |
| ELEV | Elevator position |
| RUDDER | Rudder position **including yaw damper inputs** |
