# A/P Actuator Input Crank
🔗 [[Pitch Control|← Pitch Control]]

> [!abstract]
> The Autopilot mechanically moves the Elevator Input Torque Tube through the A/P Actuator Input Crank — the same mechanical path used by pilot column inputs.

---

## Function

```
A/P Actuator → A/P Actuator Input Crank → Elevator Input Torque Tube → PCUs → Elevator
```

- A/P pitch commands enter the mechanical elevator system at the **Input Torque Tube**
- Bypasses the FWD Control Quadrant — column does not physically move with A/P pitch inputs
- Disconnect of A/P → torque tube returns to neutral under column control
