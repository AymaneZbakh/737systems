# Rudder Pedals & Quadrants
🔗 [[Yaw Control|← Yaw Control]]

---

## Pedal Connections

- Each rudder pedal set mechanically connected by cables to **input levers** of both main and standby rudder PCUs
- Both CPT and F/O pedal sets are interconnected — one set moves the other

## Forward Rudder Quadrants

- FWD rudder quadrants receive pedal input
- Connected via **Bus Rod** to the Rudder Control Cables

## Rudder Control Cables

- Route from FWD quadrants through the fuselage to **AFT Rudder Quadrant**
- AFT quadrant drives the **Rudder Torque Tube** → main and standby PCU inputs

## Key Values

| Parameter | Value |
|-----------|-------|
| Nose gear steering via pedals | 7° |
| Rudder aerodynamically effective | 40–60 kts |
| Max rudder travel | 29° L/R |
