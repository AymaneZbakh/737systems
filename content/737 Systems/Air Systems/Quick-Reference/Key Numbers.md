# 🔢 Key Numbers — All Systems

> [!abstract] Overview

## 🌬 Bleed Air System

| Value | Parameter |
|-------|-----------|
| **42 psi** | PRSOV pressure regulation limit |
| **232°C / 450°F** | PRSOV temperature limit |
| **254°C / 490°F** | Bleed Trip-Off: over-temperature threshold |
| **220 psi** | Bleed Trip-Off: over-pressure threshold |
| **199–229°C / 390–440°F** | Precooler output target temperature |
| **32 psi ±6** | Regulated 9th stage duct pressure (26–47% N1, sea level) |
| **42 psi ±8** | Regulated 5th stage duct pressure (>54% N1, sea level) |
| **18 psi** | Minimum duct pressure during T/O, climb, cruise |
| **10 psi** | Minimum duct pressure just after top of descent |
| **30 psi** | Required duct pressure for cross-bleed engine start |
| **50 psi** | High duct pressure threshold → maintenance required |
| **60 psi** | Maximum external pneumatic source pressure |
| **75 psi** | APU pressure relief valve opens |
| **17,000 ft** | APU bleed air only — maximum altitude |
| **10,000 ft** | APU bleed air + electrical load — maximum altitude |

## ❄️ Air Conditioning System

| Value | Parameter |
|-------|-----------|
| **18°C – 30°C** | Cabin zone temperature range (65°F–85°F) |
| **55 lb/min** | Pack normal flow (2 packs, AUTO) |
| **80 lb/min** | Pack HIGH flow — single pack, flaps up in-flight |
| **100 lb/min** | Pack HIGH flow — manual HIGH selection |
| **199°C / 390°F** | ACM compressor overheat limit |
| **99°C / 210°F** | ACM turbine overheat limit |
| **121°C / 250°F** | Pack discharge overheat limit |
| **88°C** | Duct temperature overheat (CONT CAB ZONE TEMP trigger) |
| **24°C / 18°C** | L pack / R pack output when all zone selectors OFF |
| **20 seconds** | OFV full travel time in manual mode |

## 🔵 Pressurisation System

| Value | Parameter |
|-------|-----------|
| **7.45 psi** | Max diff pressure — FLT ALT ≤ FL280 |
| **7.80 psi** | Max diff pressure — FLT ALT FL280–FL370 |
| **8.35 psi** | Max diff pressure — FLT ALT > FL370 |
| **8.99 psi** | Max diff pressure — BBJ, FLT ALT > FL370 |
| **8.75 psi** | AUTO FAIL triggers — excessive diff pressure |
| **9.1 psi** | Positive pressure relief valves open |
| **−1.0 psi** | Negative relief valve opens |
| **750 FPM** | Normal cabin rate limit |
| **2,000 FPM** | AUTO FAIL triggers — excessive cabin rate |
| **8,000 ft** | Normal max cabin altitude at cruise |
| **10,000 ft** | Cabin altitude warning activates |
| **14,500 ft** | OFV safety closes automatically (CPC mode) |
| **15,000 ft** | Cabin altitude = uncontrollable (regardless of rate) |
| **15,200 ft** | HIGH ALT LDG: cabin altitude warning delayed to this level |
| **15,800 ft** | AUTO FAIL triggers — high cabin altitude |
| **0.25 psi** | Diff pressure at which cruise mode activates |
| **−1,000 to 42,000 ft** | FLT ALT range (500 ft increments) |
| **−1,000 to 14,000 ft** | LAND ALT range (50 ft increments) |
| **6,000 ft** | Landing above this requires supplementary LAND ALT procedure |
