# 🔧 IFE/PASS SEAT Switch

> [!abstract] Overview
> Controls passenger-facing entertainment and seat power, independent of the main galley/cabin utility loads.

## 📋 Systems That Lose Power When OFF

| System |
|---|
| Installed components of the passenger seat |
| 115V AC cabin audio/video entertainment |
| (Certain models) Flight Deck surveillance system |
| 28V DC video equipment and passenger seat electronic outlets |
| ACARS printer |
