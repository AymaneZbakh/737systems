# 🌬 07 — Systems Available With No AC Power

> [!abstract] Overview
> If **no AC source** is available at all (all generators and ground power lost), a defined set of essential systems remain available through the [[05-DC-Standby-Power-System|standby power system]] and direct battery/DC feeds.

> [!warning] Safety-critical reference
> This table represents the **absolute minimum** equipment set. Memorize it — it defines what you can and cannot rely on in a total AC-loss scenario.

## 📊 Systems Available With NO AC Source of Power

| Category | Available Systems |
|---|---|
| **General** | Compass, Dome Light, Oxygen Systems |
| **Air Systems** | Manual Pressurization, Air Conditioning Pack Valves, PACK light |
| **Anti-Ice** | Captain Pitot Probe Heat *(no flight deck signalization)* |
| **Communication** | VHF #1 and Transponder #1, PA, Service and flight interphone |
| **Engines, APU** | Engine Instruments (N1, N2, FF, EGT, OIL Indication, REV), Fuel QTY, START Valves, R Ignition, APU start |
| **Fire Protection** | APU and Engine Fire Detection and Extinguishing bottles, Cargo extinguishing bottles **but no detection** |
| **Flight Instruments** | DUs on left side + standby instruments (Left FMC and CDU, VHF, ILS, IRS, GPS, XPDR, DME, ADF), Upper DU |
| **Fuel** | Cross-feed, Fuel QTY, Spar and Engine shut-off valves, FUEL VALVE CLOSED lights |
| **Hydraulics** | Engine and standby rudder hydraulic shutoff valves |
| **Landing Gear** | Landing gear indicator lights, Air/ground system, Inboard anti-skid system and ANTISKID INOP light |
| **Stall** | Stall warning |

> [!note] Notable gaps
> - **Cargo fire extinguishing** bottles work, but **cargo fire detection does not**.
> - Only the **left side** DUs remain — right-side displays are lost.
> - Only **VHF #1 / Transponder #1** remain — the #2 sets are lost.
