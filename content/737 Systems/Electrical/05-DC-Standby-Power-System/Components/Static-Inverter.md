# 🔧 Static Inverter

> [!abstract] Overview
> The Static Inverter converts DC battery power into single-phase AC to keep the AC Standby Bus alive when no other AC source is available.

## 📋 Key Facts

| Fact |
|---|
| Located in the **E&E bay** |
| Transforms **DC power** into **single-phase 115V, 400Hz AC** |
| Feeds the **AC Standby Bus** |
