# 🔧 APU Generator Control Unit (AGCU)

> [!abstract] Overview
> The AGCU is the APU generator's equivalent of the engine [[GCU|GCUs]] — it controls output quality and protects the system via the Auxiliary Power Breaker (APB).

## 📋 Key Facts

| Function |
|---|
| Controls the **APU generator output** and the **Auxiliary Power Breaker (APB)** |
| Protects the electrical system by tripping the APB for overcurrent, over/underfrequency, etc. |
| Provides the **same protection level** as the IDG GCUs |
