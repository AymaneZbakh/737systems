# 📊 NG vs MAX-8 — Side-by-Side Comparison
🔗 [[Home - MAX Differences]] | [[Flight controls/Summary/System Overview]]

---

## Engines

| Feature | 737 NG (CFM56-7) | 737 MAX-8 (LEAP-1B) |
|---------|-----------------|---------------------|
| Fan diameter | 1.55 m (61") | **1.75 m (69")** |
| Fan blades | 24 aluminium | **18 carbon fibre composite** |
| Bypass ratio | 5:1 | **9:1** |
| HPC ratio | 11:1 | **22:1** |
| EGT T/O limit | 950°C | **1,038°C** |
| N2 max | 105% / 15,183 RPM | **117.5% / 20,171 RPM** |
| Engine weight | Reference | +385 kg |
| Fuel saving | Reference | **~15%** |
| Battery starts | Available | **NOT available** |
| BRM | Not applicable | **Required — up to 90 sec** |
| EOS / TCMA | Not present | **New protections** |
| Core anti-ice | Manual | **Auto — managed by EEC** |
| Icing Idle | Not present | **New highest idle** |
| Chevrons | None | **Present — noise reduction** |

## Airframe

| Feature | 737 NG | 737 MAX-8 |
|---------|--------|-----------|
| Winglets | Blended winglet | **AT winglet (blended + strake)** |
| Nose strut | Standard | **+20.3 cm (8") extended** |
| Tail section | Standard | **Streamlined + extended cone** |
| Aft vortex generators | Present | **Removed** |
| Cooling eductor | Present | **Removed (APU)** |
| Static dischargers (per wing) | 2 | **6 (4 on AT winglet + 2 on tip)** |
| Main wheel well fire detection | Single loop | **Dual loop** |
| Cargo hold volume | Reference | Hold 1: −15%; Hold 4: −25% |
| 2nd fire bottle discharge | 60 min | **15 min (in-flight)** |
