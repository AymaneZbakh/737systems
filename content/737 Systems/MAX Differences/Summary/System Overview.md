# 📋 MAX-8 System Overview — Summary
🔗 [[Home - MAX Differences]]

> [!abstract]
> Single-page overview of all major differences between the 737 MAX-8 and 737 NG (737-800).

---

## Engines & Powerplant

| Item            | Change                                          |
| --------------- | ----------------------------------------------- |
| Engine type     | **CFM LEAP-1B** (replaces CFM56-7)              |
| Fan diameter    | 1.75 m (69") — +14 cm                           |
| Fan blades      | 18 carbon fibre composite (NG: 24)              |
| Bypass ratio    | 9:1 (NG: 5:1)                                   |
| Fuel saving     | ~15%                                            |
| Engine weight   | +385 kg per engine                              |
| EGT limit (T/O) | 1,038°C (NG: 950°C)                             |
| Battery starts  | Not available on MAX                            |
| BRM             | New ground start procedure — up to 90 sec total |
| EOS + TCMA      | New engine protections tested every start       |
| VTR             | New variable thrust rating (1%–30%)             |
|                 |                                                 |

---

## Airframe & Aerodynamics

| Item | Change |
|------|--------|
| Winglets | New AT winglet (blended + downward strake) |
| Nose strut | Extended +20.3 cm (8") |
| Tail section | Streamlined, cone extended |
| Aft vortex generators | Removed |
| Roll ground margins | Reduced (strikes at ~10° vs 14° for NG-800) |
| Weight (MTOM) | +3,191 kg vs 737-800 |

---

## Flight Controls

| Item | Change |
|------|--------|
| MCAS | New system — pitch stability augmentation |
| Stab cutout switch names | **PRI / B/U** (NG: MAIN ELEC / AUTO PILOT) |
| Software column cutout | New backup function |
| FCC cross trim monitor | New MCAS/STS protection |

---

## Spoilers

| Item | Change |
|------|--------|
| System type | **Fly-by-wire** (NG: mechanical) |
| Spoiler mixer | Replaced by **SCE** unit |
| Ground spoiler valve | Replaced by **GSCM** |
| New functions | LAM, MLA, EDS, EJLA |
| SPEED BRAKE EXTENDED | Also illuminates for go-around thrust / above idle |

---

## Air Systems

| Item | Change |
|------|--------|
| Control | **Digital (IASC)** (NG: pneumatic) |
| Bleed stages | **4th & 10th** (NG: 5th & 9th) |
| Single source | Can supply **both packs** in flight |
| RAM AIR FULL OPEN lights | Removed |
| BLEED light | Replaces BLEED TRIP OFF |
| EQUIP SMOKE light | New — auto-switches packs to high flow |

---

## Anti-Ice

| Item | Change |
|------|--------|
| Core anti-ice | New — auto-managed by EEC |
| Icing Idle | New highest idle regime |
| Panel lights | COWL VALVE, L/R VALVE (replaces OPEN lights) |
| ENG ANTI-ICE light | New — failure/TAI inhibited indication |

---

## APU

| Item | Change |
|------|--------|
| APU unit | Series 41 (improved reliability) |
| Inlet door | New 3-position door (like 787) |
| EGT indicator | Removed from flight deck |
| MAINT light | Removed |
| DOOR light | New — APU door position warning |

---

## Fuel

| Item | Change |
|------|--------|
| Tank capacity | −168 kg total (wing strengthening) |
| New alerts | FUEL DISAGREE, FUEL FLOW, FILTER BYPASS |
| FMC page | New FUEL PROGRESS page 5 |

---

## Landing Gear

| Item | Change |
|------|--------|
| LG lever | No OFF position |
| LG → valve connection | No mechanical connection |
| Nose wheel steering | 6° (NG: 7°) |
| Autobrake selector | Relocated to below CDUs |
| LG Lever Lock Override | Now a button (NG: trigger) |
| Wheel well fire detection | Dual loop (NG: single) |

---

## Displays & AFDS

| Item | Change |
|------|--------|
| Display size | 15.1 inch (new MDS) |
| DEUs | Replaced by DPCs |
| Flap position indicator | Now on MFD |
| Auxiliary display | New — outboard of PFDs |
| EFIS panel | New VSD switch, +/− range selector |
| INFO button | Brings up N1/SPD REF SET page |
| ENG TFR button | New — transfers engine instruments |
| Stick shaker + AFDS | A/P and F/D disengage with 1 sec delay |
