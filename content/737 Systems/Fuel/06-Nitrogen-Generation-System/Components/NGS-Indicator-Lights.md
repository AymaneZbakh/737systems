# 💡 NGS Indicator Lights

> [!abstract] Overview
> Three lights located on the operability indicator panel in the main wheel well, adjacent to the APU fire control panel.

## 📋 Light Table

| Light | Color | Meaning |
|---|---|---|
| OPERATIONAL | 🟢 Green | NGS is fully operational |
| DEGRADED | 🔵 Blue | NGS is operational but in a degraded / temporarily serviceable condition |
| INOPERATIVE | 🟠 Amber | NGS is inoperative |
| *(no light illuminated)* | — | Also indicates NGS inoperative |

> [!warning] No Flight Deck Indication
> These lights exist **only** in the main wheel well — there is no cockpit annunciation of NGS status.
