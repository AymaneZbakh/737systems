# 🔒 APU Fuel Shutoff Valve

> [!abstract] Overview
> Located on the rear spar, accessible from the wheel well, this valve is backed by the same dual-power arrangement as the engine spar shutoff valves.

## 📋 Quick Facts

| Parameter | Value |
|---|---|
| Location | Rear spar (accessed from wheel well) |
| Primary power | HOT BAT BUS |
| Backup power | [[Fuel-Shutoff-Battery\|Fuel Shutoff Battery]] |
