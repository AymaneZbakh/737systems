# 🔌 Refueling Power Control Relay

> [!abstract] Overview
> A proximity-sensor-driven relay that powers the fueling system only when the refueling door is open.

## 📋 Quick Facts

| Door State | Effect |
|---|---|
| Closed | Proximity sensor deactivates power to the fueling system |
| Open | Fueling system is powered and panel lights illuminate |

> [!note] Backup Path
> If this relay fails, the fueling panel can still be energized manually via **FUEL DOOR SWITCH BYPASS** on the [[Test-Gages-and-Fueling-Panel\|Test Gages & Fueling Panel]].
