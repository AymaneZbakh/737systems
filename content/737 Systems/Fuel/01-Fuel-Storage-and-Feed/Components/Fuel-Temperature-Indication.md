# 🌡 Fuel Temperature Indication

> [!abstract] Overview
> The FUEL TEMP indicator on the fuel control panel displays fuel temperature, sensed in Main Tank No. 1. The system is AC powered.

## 📋 Limits

| Limit | Value |
|---|---|
| Maximum fuel temperature | **49 °C** |
| Minimum fuel temperature | **−43 °C**, or 3 °C above fuel freezing point (whichever is higher) |
| Jet A-1 freezing point (reference) | ≈ −47 °C |
| Sensor location | Main Tank No. 1 |
| Power source | AC electrical |

> [!note] Why Tank No. 1?
> The sensor location is a legacy carry-over from the 737-200, where Tank No. 1 was the coldest tank and showed the most limiting temperature — caused by different-sized hydraulic heat exchangers submerged in the main tanks (HYD A had a smaller exchanger). On the 737 NG, hydraulic heat exchangers are the same size on both sides, so the temperature difference between tanks is now **negligible** — the sensor position simply never moved.
